# Statische GitHub-feed

`feed.json` kan worden gebruikt voor een eenvoudige openbare kalender zonder beheer-
API. De feed bevat geen managementrollen of ledenlijst.

Gebruik de statische feed niet voor geheime boss-codewoorden: een bestand op GitHub is
altijd openbaar. Voor tijdelijke codewoorden en toevoegen/verwijderen vanuit RuneLite
is de meegeleverde API vereist; die geeft een codewoord pas tijdens het event vrij.

De workflow mag uitsluitend verlopen events uit de statische feed verwijderen.
